# StatTile

One headline number with an `overline` label above it and a short context line below.

- The number uses the `stat` style with tabular figures, so tiles in a row line up.
- Lay tiles out in a row of 2 on phones, 4 on desktop and up to 6 at `bp-wide`.
- Color the number `gold-strong` (`nz-stat-win`) only for victories. Deaths stay `ink`: losses are information, not alarms.
- The consumer provides the label, value and an optional delta or context line.
